# Protection Reports — Product Documentation

**Sprint scope:** Design only — **no implementation, no new MCP tools.**

**Mission:** Founders receive **proof** that SequrAI protected their application — weekly rhythm, monthly record.

**We sell:** Peace of mind and continuity — not PDFs full of findings.

## Every report must answer

| Question | Primary sections |
|----------|------------------|
| **Am I becoming more protected?** | Protection summary, status trend, statistics |
| **What improved?** | Confidence trends, fixes verified, evolution |
| **What worries SequrAI?** | Worries block (max 3) |
| **What should I do next?** | Single recommendation / CTA |
